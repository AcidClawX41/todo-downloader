Coloca aquí los GIF animados que quieras mostrar en la pestaña «Invítame a algo».

- Se incrustan en el ejecutable al compilar (build.rs los detecta solos).
- Cada vez que se abre la pestaña se elige UNO al azar.
- Si esta carpeta está vacía, la pestaña funciona igual, solo que sin animación.
- Tamaño recomendado: ancho <= 660 px. Se escala manteniendo la proporción.
